Firebase Firestore Rules Setup

Fix "Missing or insufficient permissions" in 30 seconds

In Firebase Console, Cloud Firestore rules control which collections can be read or written. If default rules expired or don't include new collections, Firestore blocks requests with "Missing or insufficient permissions".

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

How to apply:

  1. Go to Firebase Console → Firestore Database → Rules.
  2. Paste the rules code above.
  3. Click Publish. All permissions are immediately enabled!
